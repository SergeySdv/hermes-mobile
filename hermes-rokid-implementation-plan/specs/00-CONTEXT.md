## Подтверждено пользователем — USER_VERIFIED

Телефон — OnePlus Open. Куплены китайские Rokid Glasses с дисплеем; точные модель, firmware и способ доступа к ADB пока не установлены. Нужен нативный клиент, похожий по удобству на ChatGPT: история, вложения, настройки и продолжение диалога на телефоне.

Hermes уже работает на VPS в изолированном контейнере; основной действующий интерфейс — Telegram. В предоставленном выводе Docker присутствуют три агента: `hermes-agent`, `personal-hermes-agent`, `eisenhorn-hermes-agent`. Проверялся первый, но принадлежность нужному Telegram-боту окончательно не подтверждена. Не выбирать production target только по имени.

| Наблюдение из терминала | Достоверный вывод |
|---|---|
| `docker exec hermes-agent hermes dashboard --help` работает | CLI и команда dashboard существуют в проверенном контейнере |
| `dashboard --status`: процессов нет | На момент проверки Dashboard не работал |
| `NetworkMode=agent-internal Ports={}` | Для этого контейнера опубликованных портов в выводе нет |
| `edge-infra-caddy-1`: 80/443 | Caddy уже принимает внешний HTTP/HTTPS |
| `dashboard register --help` | Есть интерфейс регистрации OAuth-клиента |
| `sh -lc 'hermes ...'`: not found | В этом вызове shell не нашёл CLI; прямой exec работает |

Эти наблюдения не доказывают наличие s6/supervisor, поддержку `HERMES_DASHBOARD=1` в конкретном образе, доступность сети Caddy к агенту или совместимость последнего Android-клиента с установленным Hermes.

## Продуктовые требования — DESIGN на основании задачи

| ID | Требование | Проверка |
|---|---|---|
| R01 | Агент и инструменты только на VPS | Архитектура и сборочные зависимости |
| R02 | Один UI телефона с сохранением обычных функций Hermes | Regression suite, feature-off |
| R03 | Фото очков и продолжение текстом принадлежат одному выбранному диалогу | G4 / CTX-01..04 |
| R04 | Ответ постепенно появляется на дисплее | G5 / DSP-01..04 |
| R05 | Быстрый китайский OCR/перевод на русский не ждёт Hermes | G6 / OCR-01..06 |
| R06 | Нет тихого повторного выполнения поручения после обрыва | G7 / REC-01..06 |
| R07 | Нормальная работа с погашенным экраном телефона | G7 аппаратный pocket test |
| R08 | Telegram и прочие контейнеры не ломаются | G2, G8 / OPS-01..04 |
| R09 | Явные разрешения, приватность и выбор отправки фото | SEC-01..06 |
| R10 | Можно вернуться на предыдущие APK/config | G8 rollback rehearsal |

MVP: текст, снимок по запросу, общий разговор телефона/очков, стриминг дисплея, локальный OCR/перевод, восстановление, настройки и диагностика. Полноценный голос, постоянное видео, wake word и межканальная синхронизация Telegram исключены из MVP.

## Приоритеты и ограничения масштаба

Сначала снизить риск совместимости, затем собрать узкий рабочий путь. Не начинать с универсальной plugin platform, своего сервера заданий, полной переписи UI, бесконечного видео или объединения всех каналов Hermes.

Локальный OCR и необязательный кратковременный speech preprocessing не нарушают R01: это клиентские функции, не запуск агента. При выключенной функции очков никакого постоянного сканирования Bluetooth, камеры или микрофона.
